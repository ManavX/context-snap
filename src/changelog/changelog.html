What's new in the latest update

v1.0.21 March 2026
New Feature

Auto-Save on Window Close

Your browser context is now automatically saved when you close a window. Scroll positions, form data, and text selections are all captured — so nothing is lost even if you close a window by accident.

  • Full state capture including scroll, forms, and selections
  • Enabled by default — toggle it off in Settings under Storage
  • Skips empty windows (new tabs only)
  • Saved as "Auto Save" with a timestamp for easy identification
New Feature

Pin Important Contexts

Click the star on any saved context to pin it. Pinned contexts are protected from auto-delete and max context limits — they'll never be automatically removed.

  • ★ Pinned
  • Protected from "Auto-delete after X days"
  • Protected from "Max saved contexts" limit
  • Click the star again to unpin
Bug Fix

Quick Save Now Respects Limits

Quick saves (Ctrl+Shift+S) now correctly enforce the max contexts and auto-delete settings. Previously, quick saves could exceed these limits.
